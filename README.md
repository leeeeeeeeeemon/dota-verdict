# ⚖️ КТО ЗАРУНИЛ?

Пост-матч «судебная экспертиза» катки Dota 2. Вводишь ID матча — алгоритм изучает улики и выносит вердикт: кто заруинил катку, кто настоящий MVP, и кто просто красиво фармил.

Данные — [OpenDota API](https://www.opendota.com) (бесплатный, без ключа). Зависимостей и сборки нет: это чистый HTML/CSS/JS.

## Запуск

Вариант 1 (рекомендуется) — запусти `start.bat` (двойной клик): поднимется сервер на http://127.0.0.1:8765 и откроется браузер. Сервер заодно проксирует и кэширует OpenDota API, так что приложение работает даже там, где api.opendota.com напрямую недоступен (встроенные браузеры, строгие брандмауэры), и не тратит лимит запросов впустую.

Вариант 2 — просто открой `index.html` двойным кликом (нужен доступ к api.opendota.com из браузера; в этом режиме прокси-фолбэк недоступен).

Вариант 3 — вручную:

```
cd dota-verdict
python serve.py 8765     # или: python -m http.server 8765 (только статика, без прокси)
```

## Как пользоваться

- Вставь ID матча (ссылка с opendota.com/stratz.com тоже подойдёт — номер вытащится сам) → «ВЫНЕСТИ ВЕРДИКТ».
- Не знаешь, чей матч судить? «🎲 Случайная про-катка» возьмёт свежий матч из про-сцены.
- Вердикт можно пошарить: после анализа в адресной строке остаётся `?match=<id>` — ссылка откроется и сразу вынесет вердикт.

## Что выносит суд

| Блок | Что это |
|---|---|
| 🔨 Виновник проигрыша | Игрок проигравшей команды с максимальным «индексом руинера» + список улик |
| 🏆 MVP катки | Максимальный вклад среди победителей |
| 🧤 Лучший саппорт матча | Отдельная награда лучшему саппорту (обе команды) — как в MVP-войтинге киберспорта |
| 🛡 Лучший из проигравших | Тот, кто тащил безнадёгу (иногда — «1-в-9») |
| 🔍 Разборы «Почему именно он?» | У MVP — вклад по факторам в очках + сравнение с конкурентом; у виновника — улики с долями вины и рейтинг всей команды |
| 🎒 Билды | Инвентарь с иконками и тайминги ключевых предметов у виновника и обоих MVP; покупка BKB/Radiance после 30-й минуты — отдельная улика |
| 📈 Хронология | График перевеса золота + пронумерованные ключевые моменты: скачки золота и кто «подарил» его, умерев на волне |
| 📊 Вклад каждого | В таблицах команд у всех игроков — полоска вклада (тот же скор, что у MVP) |
| 📁 Досье игрока | Клик по строке игрока в таблице: последние 10 каток, винрейт, сколько раз был виновником/MVP и приговор суда |
| Медали | 🍖 Корм матча, 👻 Призрак, 🌿 Фермер-отшельник, 👁 Вард-мастер, 🏰 Разрушитель и др. |

Если у всех счёт вины низкий — суд признаёт **коллективную вину** и никого конкретно не обвиняет.

## Как считается «степень вины» (движок в `engine.js`)

Каждый игрок проигравшей команды получает баллы по факторам (вклад 0..1 × вес):

| Фактор | Вес | Улика |
|---|---|---|
| Вышел из игры / АФК | 3.0 | `leaver_status >= 2` |
| Фид | 1.6 | доля своих смертей от смертей команды |
| Призрак | 1.3 | участие в убийствах ниже ~38% |
| Жадный фермер | 1.0 | GPM выше среднего по команде при низком участии |
| Фейковый кор | 1.0 | забрал долю ресурсов кора, а урона дал мало |
| Слепой саппорт | 0.9 | ≤2 варда за катку (если реплей распарсен) |
| Бенчмарк OpenDota | 1.2 | урон в минуту хуже 92%+ игроков на этом герое |

Сумма нормируется в проценты; <35% у всех → коллективная вина. MVP считается из очков по факторам: участие (до 34), урон и вышки — **относительно нормы роли** по рангу фарма (до 22 и 12; керри должен отработать ~30% урона команды, пятая позиция — ~8%), KDA (до 12), лечение (до 10) и варды/опыт (до 10; без парса реплея саппорту за варды даётся нейтрально 5/10). Замер на 40 матчах: саппорты берут MVP в ~15–20% каток. Пустые (ещё не обработанные) матчи отклоняются с сообщением «попробуй позже».

## Структура

- `index.html` / `style.css` — страница и тёмная тема в духе клиента Dota
- `engine.js` — чистая логика вердиктов (без DOM, тестируется в Node: `node test.js`)
- `app.js` — работа с OpenDota, рендер, canvas-график перевеса
- `test.js` — смоук-тест движка на матче из `fixtures/match.json`

## Ограничения

- Для свежих матчей OpenDota мог не успеть распарсить реплей: тогда нет вардов, графика и бенчмарков — в интерфейсе есть кнопка «Запросить парсинг».
- Анонимные матчи (все игроки скрыты) дадут скучный вердикт — улик мало.
- Это шутка, а не объективная истина: не оскорбляйте тиммейтов на основании вердикта 🙂
